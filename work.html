作業内容

実際の仕事を通して、 ITスキルと働く経験を身につけます。

01 / WEB DEVELOPMENT

Webサイト制作・コーディング

HTML / CSS / JavaScript / WordPress

企業サイト・LPのコーディング、 既存サイトの更新作業、 WordPressの記事投稿・カスタマイズなど、 Web制作の実務に関わります。 デザインカンプからのコーディングをメインに、 静的サイトのマークアップから 運用作業まで幅広く対応します。

TOOLS VS Code / Git
DIFFICULTY 中級
WAGE 時給 400〜600円
実績例 地元企業のコーポレートサイト 全ページのコーディング、 飲食店ホームページの月次更新、 WordPressテーマの改修など。
02 / DESIGN

デザイン制作

Photoshop / Illustrator / Figma

Webバナー、店舗チラシ、 SNS投稿用画像、名刺、 ロゴのブラッシュアップなどを制作します。 テンプレートを使った作業から、 オリジナルのビジュアル制作まで、 経験に応じてステップアップできます。

TOOLS Adobe / Figma
DIFFICULTY 初級〜中級
WAGE 時給 350〜550円
実績例 EC事業者向けInstagram投稿画像 月80枚、地域イベントのチラシデザイン、 YouTubeサムネイル制作など。
03 / VIDEO EDITING

動画編集

Premiere Pro / DaVinci Resolve / CapCut

YouTube動画のカット編集、 字幕・テロップ挿入、 SNS向けショート動画の制作を行います。 素材の整理からBGM選定、 書き出しまで、 動画1本を仕上げるまでの 一連の流れを経験できます。

TOOLS Premiere / CapCut
DIFFICULTY 初級〜中級
WAGE 時給 400〜600円
実績例 YouTubeチャンネル運営者様の 動画編集（週2本）、 企業採用動画の字幕付け、 TikTok向けショート量産など。
